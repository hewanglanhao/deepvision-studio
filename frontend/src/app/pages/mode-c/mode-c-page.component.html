Mode C

CNN Explainer Embedded Module

Mode C now acts as a host shell for the standalone cnn-explainer app. The Angular page keeps the platform navigation, while the explainer itself runs inside an isolated iframe to avoid conflicts with Svelte, D3, TensorFlow.js, and global styles.

Sync Command {{ syncCommand }}
01 Build CNN Explainer

In D:\VS Code\cnn-explainer, run npm install once, then npm run build to generate bundle.js and bundle.css.

02 Sync Static Files

Back in this repo, run {{ syncCommand }}. The script copies the built app into frontend/public/modules/cnn-explainer.

03 Reload Mode C

Refresh this page after syncing. If the iframe stays blank, the build output is usually still missing from the source project.

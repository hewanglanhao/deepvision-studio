模块定位

成员 A 模块：Mode A 数据链路与交付价值

数据流
  • 用户在 Mode A 中完成样本选择、网络搭建和参数调整。
  • 前端将图片和网络结构整理成统一请求，由 Spring 转发到 Python forward 服务。
  • Python 返回逐层 shape、特征图、Top-K 和错误提示，页面再用于检查器展示、历史保存和结果复用。
  • 登录用户可以保存完整实验快照，后续恢复网络、输入和结果状态。
页面能力
层检查器展示当前层输入输出 shape、公式说明、统计值和特征图。
输出结果在同一页面查看预测排名、层级形状变化和异常提示。
实验快照保存网络结构、连接关系、计算结果和输入图片信息。
结果复用同一份实验结果可继续用于检查器、历史记录、助手和 3D 页面。

成员 C 模块：重构路径与工程难点

重构路径
  1. 先以嵌入方式验证 CNN Explainer 可在平台内运行，再逐步拆掉外部依赖。
  2. 从 Overview 开始重建 Angular 原生骨架，再逐层补回卷积、ReLU、池化和输出层的解释视图。
  3. 把用户状态、AI 助手、教学入口和平台统一样式接进 Mode C，完成模块化收口。
工程难点
  • 原项目是 Svelte 加静态资源驱动，无法直接复用为 Angular 组件，只能按功能拆解后重建。
  • 需要把总览拓扑和局部教学弹层解耦，同时保持真实推理数据和页面交互同步。
  • 卷积层演示不是静态插图，而是基于真实通道、真实 kernel 和真实输出位置组织逐步动画。
模块价值
  • 这部分工作的价值不是"把别人项目嵌进来"，而是把外部解释器改造成平台内统一架构下的教学组件。
  • Mode C 现在既有可视化总览，也能下钻到单层、单通道、单 patch 的局部计算过程。
  • 它和 Mode A、Mode D 共用用户体系、教学入口和 AI 辅助能力，体现了平台化复用而不是单页 demo。
这一页重点讲"为什么难"和"为什么值得"。如果老师问和原始 CNN Explainer 的关系，可以回答为参考其教学目标，但实现已经重构到平台自己的 Angular 架构中。

成员 D 模块：QKV 教学与工程实现

QKV 教学结构
  • 不是只画出注意力矩阵，而是把 Query × Key、缩放、softmax、Value 汇入输出的链路逐步展开。
  • 让用户能把"某个格子为什么亮"和"它最终如何影响输出 token"联系起来理解。
  • 这种设计更适合课程答辩，因为它既能讲公式，也能讲交互和最终效果。
工程难点
  • 浏览器端 Transformer 运行时需要处理 tokenizer、ONNX Runtime、注意力张量提取和静态资源分发问题。
  • 教学可视化不等于直接把张量打印出来，还需要把高维 attention 和 QKV 过程压缩成人能看懂的交互界面。
  • 资源较大，因此又做了"源码保留、模型资源单独同步"的改造，降低仓库体积和协作成本。
模块价值
  • Mode D 的核心贡献是把 Transformer 的预测结果与内部依据放到同一页面里，用教学化方式串起来。
  • 不是只演示 attention matrix，而是把 Top-K、当前聚焦单元和 QKV 信息流一起解释。
  • 这一模块也复用了平台统一的 AI 与教学体系，说明平台不仅能承载 CNN，也能扩展到 Transformer 解释场景。
这一页讲完以后，老师基本就能理解 Mode D 不只是"又一个页面"，而是把 Transformer 教学、浏览器端推理和平台化接入结合在一起。

模式 E：反向传播引擎与子步骤动画

纯前端 MLP 引擎（零依赖）
  • 手写矩阵运算：dot、transpose、hadamard、softmax — 无任何数值库依赖
  • 完整实现 Dense 层、ReLU/Sigmoid/Tanh 激活函数的正向和反向传播
  • CrossEntropy / MSE 损失 + Softmax 合并梯度优化
  • SGD / Momentum / Adam 三种优化器，每种都有独立的动量/二阶矩状态
逐层子步骤动画状态机
idle → forward-0-1 → forward-1-2 → ... → loss
     → backward-2-1 → backward-1-0
     → update-1 → update-2 → done
  • 每个子步骤手动推进（用户点击"继续"），进度条实时显示
  • 蓝色脉冲 = 前向数据流、橙色脉冲 = 反向梯度流、绿色脉冲 = 参数更新
  • 流动光点沿权重边线动画移动，直观展示数据传递方向
教学价值不是瞬间跳过训练过程，而是把每一步拆成逐层可视化的教学演示，让"反向传播"四个字变成能看到的动画。
先讲引擎架构（自己写矩阵运算，不依赖任何库），再讲动画状态机设计。

模式 E：神经元连线图与决策边界

神经元权重连线图
  • SVG 绘制每层神经元节点 + 层间全连接权重边，连线颜色=阶段，粗细=幅度
  • 点击神经元：显示选中高亮环 + 详情面板列出该神经元所有入边/出边的权重和偏置
  • 悬停连线：弹出白色浮层显示权重值 / 梯度值 / 变化前后的数值
  • 子步骤动画时当前计算的层对有彩色外圈高亮标注
决策边界与图表系统
  • 50×50 网格实时计算分类结果，半透明色块叠加在散点图上
  • 每 25 步更新，数据点坐标根据实际范围动态映射（解决溢出问题）
  • 左侧浮层面板：数据集散点图 + 损失曲线对比 + 当前预测
